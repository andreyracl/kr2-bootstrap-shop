# Квест-Лаборатория — сеть квест-комнат

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Учебный сайт сети квест-комнат. Посетитель смотрит каталог квестов с фильтрами по сложности, жанру, возрасту и количеству игроков, открывает страницу квеста с описанием и фотографиями, проверяет свободное время и оставляет заявку на бронирование.

## Ссылки

- Репозиторий: https://github.com/andreyracl/kr2-bootstrap-shop
- GitHub Pages: https://andreyracl.github.io/kr2-bootstrap-shop/

## Используемый фреймворк

Bootstrap 5.3.8. Тёмная тема включена встроенным механизмом Bootstrap — атрибутом `data-bs-theme="dark"` у тега `<html>`.

## Способ подключения Bootstrap

Bootstrap подключён через CDN jsDelivr:

- CSS — `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css` в `<head>`;
- JS Bundle — `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js` перед `</body>`.

Собственный файл `css/custom.css` подключается после Bootstrap, чтобы переопределять его переменные и стили.

## Как посмотреть проект

- Онлайн: открыть ссылку GitHub Pages.
- Локально: открыть `index.html` в браузере или запустить расширение Live Server в VS Code. Нужен интернет, потому что Bootstrap и шрифты подключены через CDN.

## Bootstrap-сетка

- `container` — основное содержимое всех страниц;
- `row` + `col-12 col-md-6 col-xl-4` — каталог: 1 колонка на телефоне, 2 на планшете, 3 на широком экране;
- `col-12 col-lg-3` + `col-12 col-lg-9` — каталог: фильтры и список квестов;
- `col-12 col-lg-7` + `col-12 col-lg-5` — главная и страница квеста: две колонки на больших экранах;
- `g-4`, `g-lg-5` — промежутки между колонками.

## Реализованные компоненты Bootstrap

Обязательные:

- `navbar` — единая навигация на всех страницах внутри `<header>`, сворачивается в «бургер» на мобильных;
- `card` — карточки квестов, филиалов, блоки формы; карточки категорий с подписью поверх картинки (`card-img-overlay`);
- `btn` — варианты `btn-primary`, `btn-outline-primary`, `btn-outline-light`, `btn-outline-secondary`, размеры `btn-lg`, `btn-sm`;
- `badge` — «Хит», «Новинка», «С актёром», возрастное ограничение;
- `alert` — подсказки в каталоге и в форме заявки, предупреждение о возрасте на странице квеста, сообщение «ничего не найдено»;
- `modal` — быстрое бронирование с любой страницы;
- `form-control`, `form-select`, `input-group`, `form-check` — формы бронирования и заявки.

Дополнительные:

- `carousel` — 2 иллюстрации квеста на его странице;
- `accordion` — частые вопросы на главной и на странице контактов, «Как выбрать квест» в каталоге;
- `offcanvas` — фильтры каталога выезжают сбоку на мобильных (`offcanvas-lg`), на компьютере стоят в колонке;
- `toast` — уведомление об отправленной заявке;
- `breadcrumb` — хлебные крошки на внутренних страницах;
- `table table-striped table-bordered` — характеристики квеста;
- `form-switch`, `btn-check` — переключатель рассылки и выбор повода в заявке;
- встроенная валидация форм Bootstrap (`needs-validation`, `was-validated`, `invalid-feedback`).

## Самостоятельные доработки

- **Расширенный набор страниц:** 13 страниц квестов, страница контактов.
- **Каталог с работающими фильтрами** по сложности, жанру, особенностям (с актёром, новинка, хит), возрасту младшего игрока и количеству игроков; счётчик найденных квестов; сообщение и кнопка сброса, если ничего не найдено.
- **Категории квестов на главной:** горизонтальная лента из 8 карточек (нестрашные, страшные, для детей, с актёрами, новинки, для новичков, для опытных, для компании от 6 человек) с прокруткой кнопками. Каждая карточка ведёт в каталог с уже включённым фильтром через параметры адреса (`catalog.html?scare=no`, `?age=12`, `?feature=actor`, `?players=6`).
- **Расписание сеансов** на странице квеста: три дня друг под другом, свободные и занятые слоты, цена каждого сеанса. Нажатие на свободное время открывает модальное окно, где уже подставлены квест, день и время; в окне можно оставить комментарий. Кнопка «Забронировать» в карточках каталога и главной ведёт сразу к расписанию нужного квеста (`quest-*.html#schedule`), поэтому пользователю не нужно выбирать квест по памяти.
- **Страница квеста:** развёрнутый сюжет, правила, блок «Особенности» со списком «Вас ждёт» и дополнительными услугами (фото, видео прохождения, наблюдение через камеры, сопровождение для команд с детьми).
- **Доплата за игрока:** базовая цена рассчитана на команду до 4 человек (в квестах до 4 игроков — до 2). За каждого следующего игрока: 500 ₽ в нестрашных и недорогих квестах, 1 000 ₽ в мистических и дорогих, 1 500 ₽ в хоррор-квестах.
- **Режим игры в хоррор-квестах** («Палата №13», «Последний сеанс»): три уровня контакта с актёром — лайт (без касаний), медиум (касания руки и плеча) и хард (удержание, отдельная комната). Выбор сделан карточками-переключателями (`btn-check` + `card`) и переносится в форму бронирования. В модальном окне и на странице заявки поле «Режим игры» появляется только при выборе хоррор-квеста.
- **Отзывы:** блок «Отзывы игроков» на главной со средней оценкой и 6 отзывами; на странице каждого квеста — свои 3 отзыва и средний рейтинг квеста. Звёзды рейтинга доступны для экранного диктора (`aria-label="Оценка 5 из 5"`).
- **Несколько вариантов карточек:** обычная, «Хит» (выделена рамкой), «Новинка»; индикатор сложности из трёх точек своего цвета для каждого уровня.
- **Улучшенная форма заявки:** группировка полей в `fieldset`, выбор квеста по группам сложности (`optgroup`), повод игры, способ связи, понятные тексты ошибок, отметка обязательных полей.
- **Изображения квестов:** для каждого квеста по 2 картинки (комната и деталь загадки), сгенерированы нейросетью по собственным промптам в едином стиле, обрезаны до 4:3 и сжаты до 80–180 КБ. Иллюстрации категорий нарисованы в SVG.
- **Собственная тёмная тема:** переопределены CSS-переменные Bootstrap в `custom.css` (фон, акцентный цвет, кнопки, ссылки, шрифты), подключён шрифт Manrope.
- **Адаптивность:** проверено на ширине 375, 768, 1024 и 1440 px (как требует практика 10); на мобильных фильтры уходят в offcanvas, на компьютере фильтр «прилипает» при прокрутке.
- **Доступность:** ссылка «Перейти к содержимому», `aria-label` у кнопок без текста, `aria-current` в навигации и хлебных крошках, видимый фокус, учёт настройки «уменьшить движение».

## Как проверить

1. Открыть `catalog.html`, отметить «Сложный» — должно остаться 6 квестов; добавить «8 игроков» — останется только «Бункер-47».
2. На главной нажать карточку категории «Страшные» — откроется каталог с 4 квестами; «Для детей» — 6 квестов для детей 12 лет и младше.
3. Открыть страницу квеста, нажать свободное время в расписании — в модальном окне подставятся квест, день и время.
4. Отправить пустую форму — поля подсветятся с подсказками; заполнить и отправить — появится уведомление.
5. В DevTools включить мобильный режим: меню сворачивается, фильтры открываются кнопкой «Фильтры».
